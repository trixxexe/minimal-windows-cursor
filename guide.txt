--------------------------------------------------------------------------------
                           HOW TO INSTALL & APPLY
--------------------------------------------------------------------------------

METHOD 1: Instant 1-Click Live Install (Recommended)
---------------------------------------------------
1. Right-click "Install_Live_by_ritam.ps1" and choose "Run with PowerShell".
2. The theme will apply immediately to your current desktop session!
   (Compatible with both Windows PowerShell 5.1 and modern PowerShell 7 / pwsh).

   Want the vibrant blue arrow variant instead?
   Open PowerShell in this folder and run:
   .\Install_Live_by_ritam.ps1 -Variant vibrant


METHOD 2: Standard Windows Right-Click Install (.INF)
-----------------------------------------------------
1. Right-click "Install_by_ritam.inf" and select "Install" 
   (on Windows 11, click "Show more options" -> "Install").
2. Windows will copy the cursor files into your C:\Windows\Cursors folder 
   and register the scheme "Minimal (by ritam)".
3. Press Win + R, type: main.cpl ,,1 and press Enter.
4. Under the "Scheme" dropdown, select "Minimal (by ritam)".
5. Click "Apply" and "OK".


METHOD 3: Manual Selection via Windows Settings
-----------------------------------------------
1. Press Win + R, type: main.cpl ,,1 and hit Enter.
2. Under "Customize", select "Normal Select" and click "Browse...".
3. Navigate to where you unzipped this pack, select "minimal_arrow_ritam.cur", 
   and click "Open".
4. Repeat for any other cursors you want, click "Save As...", give it a name, 
   and click "Apply".


--------------------------------------------------------------------------------
                              HOW TO UNINSTALL
--------------------------------------------------------------------------------
To revert back to your standard Windows default cursor scheme anytime:
- Right-click "Uninstall_by_ritam.ps1" and choose "Run with PowerShell", OR
- Open Mouse Properties (main.cpl ,,1), select "(None)" or "Windows Default" 
  from the Scheme dropdown, and click "Apply".
